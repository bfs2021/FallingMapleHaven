# 默契问答系统题库修改稿

> 基于 `Docs/14-默契问答系统题库候选稿.md` 扩充修订。适用场景为新版“主页主人创建测试，登录用户或未登录访客参与答题”的默契问答插件。

## 1. 审核口径

题库题应服务于“猜主页主人会怎么选”，而不是让两个人回忆专属经历。系统题库不设置标准答案，主页主人复制到测试后自行选择自己的答案。

本稿遵守以下内容原则：

- 保留低门槛偏好、习惯、沟通方式、价值判断和轻松脑洞题。
- 删除或改写强依赖两个人共同经历的问题。
- 降低过度私密、恋爱化、审判感、金钱风险、外貌评价和家庭敏感内容。
- 题目文案控制在 80 个字符以内，选项文案控制在 30 个字符以内。
- 每题 2-4 个选项，允许“是 / 否”判断题、二选一、三选一和四选一。
- 适合高中同学、朋友、熟人和主页访客传播。

## 2. 扩充说明

本稿从原 100 题扩充为 200 题，保留原有轻社交题型，并新增更多生活类、风景偏好、校园日常、内容消费、空间感、简单判断题等题目。表格统一使用“选项”列，便于混排不同数量选项。

主要处理原则如下：

- 不再要求每题固定四选项，但仍严格保持每题 2-4 个选项。
- 将“脑洞与共同回忆”调整为“脑洞与轻松联想”，避免两人专属记忆题。
- 新增“饮食与风景偏好”“校园与日常小事”两类，覆盖更生活化的测试题。
- 对借钱、翻手机、外貌评价、关系占有欲等题目进行降敏或替换。
