## 3. 角色权限体系

### 3.1 三级角色

| 角色 | 数量 | 权限 |
|------|------|------|
| **组长** (owner) | 1 人（创建者自动担任，可转让） | 全部管理权 |
| **管理员** (admin) | 0 ~ N 人（由组长任命） | 协助管理 |
| **成员** (member) | 不限 | 内容消费与生产 |

## 4. 小组生命周期

### 4.1 创建

**前置条件**：已登录用户

**必填字段**：
- 名称（最长 100 字）
- 是否公开（ToggleSwitch）

**选填字段**：
- 简介
- 封面图（上传，自动裁切为 4:1 横幅比例）

**流程**：
1. 填写表单 → 提交
2. 系统创建 InterestGroup 记录
3. 自动创建 GroupMember（创建者 role=admin）
4. 自动创建关联 ChatRoom（type=group, group_id=当前小组）
5. 自动将创建者加入 ChatRoomMember
6. 返回成功，跳转到小组详情页

### 4.2 加入

#### 4.2.1 公开小组
- 任意已登录用户点击「加入小组」→ 直接成为成员
- 无需审批
- 自动同步加入聊天室

#### 4.2.2 私密小组
- 用户点击「加入小组」→ 提交加入申请
- 生成 GroupJoinRequest 记录（状态: pending）
- 发送通知给所有组长和管理员
- 组长/管理员在成员Tab的「申请列表」中审批（同意/拒绝）
- 同意 → 创建 GroupMember → 同步加入聊天室 → 通知申请者
- 拒绝 → 更新申请状态为 rejected → 通知申请者

### 4.3 退出

- 管理员和成员可随时退出
- 退出后自动从聊天室移除
- **组长不可退出**（必须先转让组长，或解散小组）

### 4.4 转让组长

- 仅组长可操作
- 选择任意一名成员作为新组长
- 新旧组长角色互换（原组长降为成员，新成员升为组长）
- 即时生效，无需对方确认

### 4.5 解散小组

- 仅组长可操作
- **二次确认**弹窗，提示不可恢复
- 执行操作：
  1. 删除所有 GroupMember
  2. 删除关联 ChatRoom + ChatRoomMember + Message
  3. 将关联 Post 的 group_id 置空（保留帖子，不删内容）
  4. 删除 InterestGroup
  5. 记录操作日志
- 跳转到群组列表页

## 5. 组内动态

### 5.1 内容规格

| 属性 | 规格 |
|------|------|
| 文字 | 最长 2000 字 |
| 图片 | 最多 9 张，格式 jpg/png/gif/webp |
| 文件 | 支持，与广场动态一致，单文件 ≤ 50MB |

### 5.2 可见性

- **严格隔离**：组内动态 `group_id IS NOT NULL`，不出现在广场 (`PostListView` 需过滤)
- **选择性同步**：发布时提供开关「同步到个人主页」，默认为关
  - 开启后帖子同时出现在个人主页的时间线中
  - 个人主页展示时标注「来自 XX 小组」

### 5.3 互动

采用与广场动态一致的 PostCard 组件：
- 点赞/取消点赞
- 评论（嵌套回复预留）
- 删除（仅作者或组长/管理员可删除）

## 6. 聊天室

### 6.1 创建

- **自动创建**：创建小组时，系统自动生成一个关联的 ChatRoom
  - `room.type = "group"`
  - `room.group_id = InterestGroup.id`
  - `room.name = InterestGroup.name`

### 6.2 成员同步

- **自动同步**：
  - 用户加入小组 → 自动加入 ChatRoomMember
  - 用户退出/被移除 → 自动从 ChatRoomMember 移除
- 聊天室成员列表**不可手动管理**（随群组成员自动变化）

### 6.3 入口

- 小组详情页信息卡下方添加「进入聊天室」按钮
- 点击跳转到 ChatRoomPage（复用现有聊天组件）
- 聊天列表页中小组聊天室与其他聊天室并列展示

## 7. 通知

### 7.1 新增通知类型

| 类型标识 | 触发条件 | 接收方 | 内容 | 跳转链接 |
|----------|----------|--------|------|----------|
| `group_join_request` | 用户申请加入私密小组 | 组长 + 所有管理员 | 「{用户名} 申请加入 {小组名}」 | 小组详情页成员Tab |
| `group_request_approved` | 加入申请被同意 | 申请者 | 「你的加入 {小组名} 申请已通过」 | 小组详情页 |
| `group_request_rejected` | 加入申请被拒绝 | 申请者 | 「你的加入 {小组名} 申请已被拒绝」 | 无 |
| `group_member_joined` | 新成员加入小组 | 全体成员 | 「欢迎 {用户名} 加入 {小组名}」 | 小组详情页 |
| `group_new_post` | 组内发布新动态 | 全体成员（发布者本人除外） | 「{用户名} 在 {小组名} 发布了新动态」 | 对应帖子 |

### 7.2 通知设置

- 用户可在设置中选择是否接收「组内新动态」通知（默认开启）
- 其他通知类型不可关闭

## 8. 管理员后台

### 8.1 群组管理页面

在现有管理后台中扩展「群组管理」页面，功能包括：

| 功能 | 说明 |
|------|------|
| 群组列表 | 展示所有群组，支持按名称搜索 |
| 群组详情 | 查看群组信息、成员列表、动态列表 |
| 删除群组 | 强制解散，记录操作日志（操作人、时间、原因） |
| 删除组内动态 | 跨组管理违规内容 |

### 8.2 权限

- 仅超级管理员和站点管理员可操作
- 所有管理操作记录到 SiteLog

## 9. 数据模型补充

### 9.1 GroupJoinRequest（新增）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BigAutoField | PK | |
| group | FK→InterestGroup | NOT NULL, CASCADE | 目标小组 |
| applicant | FK→User | NOT NULL, CASCADE | 申请者 |
| status | CharField(20) | default="pending" | pending / approved / rejected |
| handled_by | FK→User | NULL, SET_NULL | 审批人 |
| handled_at | DateTimeField | NULL | 审批时间 |
| created_at | DateTimeField | auto_now_add | 申请时间 |

**唯一约束**：(group, applicant) — 每人每组只能有一个待处理的申请。

### 9.2 ChatRoom 现有字段利用

`chat_chatroom.group_id`（已存在，FK→InterestGroup，NULL）
- 值为 NULL → 普通私聊或群聊
- 值非 NULL → 小组关联聊天室
- `type` 字段增加 `"group_chat"` 类型

## 10. 验收标准

### 10.1 基本流程

| # | 场景 | 步骤 | 预期结果 |
|---|------|------|----------|
| 1 | 创建公开小组 | 填写名称/简介 → 上传封面 → 提交 | 创建成功，自动成为组长，自动建聊天室 |
| 2 | 创建私密小组 | 关闭「公开」开关 → 提交 | 创建成功，私密徽章显示 |
| 3 | 加入公开小组 | 已登录用户点击加入 | 立即成为成员，同步进聊天室 |
| 4 | 申请私密小组 | 非成员点击加入 | 提示「已发送申请」，通知组长/管理员 |
| 5 | 审批加入申请 | 组长/管理员同意 | 申请者成为成员，收到通知 |
| 6 | 组内发动态 | 成员发布文字+图片 | 帖子出现在组内动态列表 |
| 7 | 广场隔离 | 查看广场首页 | 组内动态不可见 |
| 8 | 个人主页同步 | 开启同步开关发布 | 帖子出现在个人主页，标注来源 |
| 9 | 退出小组 | 成员退出 | 聊天室同步移除 |
| 10 | 转让组长 | 组长选择成员转让 | 角色互换，即时生效 |
| 11 | 解散小组 | 组长二次确认后操作 | 小组消失，动态保留但 group_id 置空 |
| 12 | 管理员后台 | 管理员查看群组列表 → 删除违规群组 | 操作成功，日志记录 |

### 10.2 权限验证

| # | 场景 | 预期结果 |
|---|------|----------|
| 13 | 非成员查看组内动态 | 403 / 提示「加入后可查看」 |
| 14 | 非组长编辑小组信息 | 403 |
| 15 | 非组长/管理员审批申请 | 403 |
| 16 | 非组长解散小组 | 403 |
| 17 | 未登录用户查看私密小组 | 跳转登录 |
| 18 | 管理员不能移除组长 | 403 |

## 11. 与当前实现的差异对照

| 维度 | 当前实现 | 目标规格 | 工作量 |
|------|----------|----------|--------|
| 广场隔离 | PostListView 未过滤 group_id | 加 filter(group_id__isnull=True) | 1行 |
| 创建封面 | 弹窗无文件上传 | 弹窗加文件上传 | 小 |
| 编辑小组 | 后端有 update API，前端无封装 | 前端加编辑弹窗 | 中 |
| 成员管理 | 后端有 manage API，前端无封装 | 成员Tab加管理菜单 | 中 |
| 私密申请 | 返回 403 不支持 | 申请+审批流程 | 大 |
| 转让组长 | 无 | 新端点+UI | 中 |
| 解散小组 | 无 | 新端点+UI | 中 |
| 聊天室 | ChatRoom 有 group_id FK，无集成 | 自动创建+同步+入口 | 中 |
| 通知 | 无群组相关通知类型 | 4种新通知类型 | 中 |
| 后台管理 | 无群组管理页面 | 新增群组管理页面 | 中 |
| 个人同步 | 无同步机制 | 发布时可选同步到主页 | 小 |
