# 插件产品定位优化方案 — FallingMapleHaven

> 版本: v1.0  
> 面向读者: 全栈开发  
> 状态: 定稿

---

## 一、概述

### 1.1 背景

当前插件在平台中处于附属地位：个人主页底部一排小卡片，没有全局入口，没有独立页面，用户不易发现和使用。但插件（默契问答、匿名提问箱）实际上是平台的差异化核心——同学朋友间的互动趣味主要靠这些工具承载。

### 1.2 目标

将插件从「附属点缀」提升为「平台核心功能线」，具体目标：

| 目标 | 说明 |
|------|------|
| **全局可见** | 导航栏增加插件入口，用户随时可找到 |
| **独立阵地** | 插件有自己独立的 Tab 页面，不再是个人主页的附属 |
| **数据驱动** | 插件卡片展示关键数据摘要，吸引点击 |
| **可控灵活** | 用户可开关主页上的插件区和留言板/足迹模块 |
| **功能增强** | 默契问答内增加好友排行榜，深化社交互动 |

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| **轻量不侵入** | 不改变插件本身的交互方式，只优化入口和展示 |
| **渐进暴露** | 未启用的插件也可见（标灰），引导用户发现和启用 |
| **数据先行** | 所有插件卡片优先展示数据摘要，让用户不点进去也能看到关键信息 |
| **尊重选择** | 用户可以决定主页上显示哪些功能模块 |

## 二、详细方案

### 2.1 独立插件页 `/plugins`

#### 2.1.1 页面定位

纯启动器页面，不承载插件具体功能，只负责展示插件列表和引导跳转。

#### 2.1.2 布局

单列列表布局，从上到下依次排列：

```
┌─────────────────────────────────────────────┐
│  🧩 互动工具                              │
│                                              │
│  ┌─────────────────────────────────────────┐ │
│  │  💞 默契问答             匹配度 87% ▶  │ │
│  │  和朋友默契大考验                      │ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┐ │
│  │  🕵️ 匿名提问箱          3 条未答 ▶    │ │
│  │  让朋友匿名向你提问                     │ │
│  └─────────────────────────────────────────┘ │
│  ┌─────────────────────────────────────────┐ │
│  │  📋 留言板              12 条留言 ▶    │ │
│  │  在朋友主页留下你想说的话               │ │
│  └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

#### 2.1.3 显示规则

- **已启用的插件**：正常显示，带彩色图标和数据摘要，右侧箭头引导跳转
- **未启用的插件**：灰色显示，卡片右侧显示「启用」按钮，点击后启用
- 所有插件均展示，不存在隐藏项

#### 2.1.4 数据摘要规则

| 插件 | 摘要数据 |
|------|---------|
| 默契问答 | 当前登录用户与所有好友的平均匹配度 / 最高匹配好友及匹配度 |
| 匿名提问箱 | 未回答的提问数量 / 总收到提问数 |
| 留言板 | 收到的留言总数 |
| 默契排行榜* | 当前排名 / 参与好友总数 |

> *默契排行榜是默契问答的内部功能，不单独作为独立插件展示

### 2.2 导航栏插件入口

#### 2.2.1 位置

桌面端 NavBar 和手机端 MobileTabBar 均在「小组」和「聊天」之间插入「插件」入口。

```
首页 → 广场 → 🧩 插件 → 小组 → 聊天 → 通知 → [头像+下拉]
```

手机端底部栏 6 个图标变为 7 个：

```
🏠 首页  |  🌐 广场  |  🧩 插件  |  👥 小组  |  💬 聊天  |  🔔 通知  |  👤 我
```

#### 2.2.2 行为

- 未登录访客：点击跳转登录页
- 已登录用户：点击进入 `/plugins`

---

### 2.3 主页模块显示开关

#### 2.3.1 入口

设置页新增一个子页面「主页模块管理」，通过 Tab 或侧列菜单进入。

#### 2.3.2 可开关模块

| 模块 | 默认状态 | 说明 |
|------|---------|------|
| 资料卡 | 固定显示 | 不可关闭 |
| 动态时间线 | 固定显示 | 不可关闭 |
| 插件入口区 | 开启 | 插件卡片网格区域 |
| 留言板 | 开启 | 留言板预览区域 |
| 访客足迹 | 开启 | 访客足迹 Tab |

#### 2.3.3 UI 示意

```
设置 / 主页模块管理

┌──────────────────────────┐
│  资料卡          — 固定  │
│  动态时间线      — 固定  │
│  插件入口区      ◉ 开启  │
│  留言板          ◉ 开启  │
│  访客足迹        ◉ 开启  │
└──────────────────────────┘
```

每个开关是 ToggleSwitch 组件，点击立即生效，无需保存按钮。

### 2.4 插件卡片数据摘要

#### 2.4.1 适用位置

个人主页的 `PluginEntryGrid` 组件中的每张插件卡片。

#### 2.4.2 卡片内容结构

```
┌──────────────────────┐
│  💞 默契问答          │
│  与好友平均匹配度 87%  │
│  最佳拍档：李四 92%   │
│                       │
│         点击进入 ▶    │
└──────────────────────┘
```

每张卡片包含：

| 区域 | 内容 |
|------|------|
| 图标 | 插件标识 emoji/图标 |
| 名称 | 插件显示名称 |
| 主要数据 | 最核心的 1-2 个数字（大字突出） |
| 次要数据 | 补充说明（小字） |
| 操作 | 「点击进入」或箭头 |

#### 2.4.3 各卡片数据

| 插件 | 主要数据 | 次要数据 |
|------|---------|---------|
| 默契问答 | 与当前浏览者的匹配度（如 A看B的主页，显示A与B的匹配度） | 答过几题 |
| 匿名提问箱 | 未答提问数 | 总计收到提问数 |
| 留言板 | 留言总数 | 最新留言时间 |

> 默契问答卡片的数据是**动态的**：不同访客看到的数据不同。张三看李四的主页，卡片显示张三与李四的匹配度；李四自己看自己的主页，显示平均匹配度。

### 2.5 默契问答内新增好友排行榜

#### 2.5.1 定位

不是独立插件，而是默契问答 `QuizPage` 内的一个功能 Tab。

#### 2.5.2 页面结构

QuizPage 现有 Tab 变为：

```
┌─────────────┬──────────────┬──────────────┐
│  出题       │  答题        │  📊 好友排行  │
└─────────────┴──────────────┴──────────────┘
```

#### 2.5.3 排行榜展示

```
📊 好友默契排行榜

🥇 李四      92%     共答题 13 道
🥈 王五      85%     共答题 8 道
🥉 赵六      78%     共答题 5 道
  4. 孙七    70%     共答题 10 道
  5. 周八    65%     共答题 3 道
  6. 吴九    60%     共答题 7 道

━━━━━━━━━━━━━━━━━━━━━━━
你的平均匹配度：75%  |  已与 6 位好友答题
```

#### 2.5.4 排序规则

- 默认按匹配度从高到低排列
- 匹配度相同则按答题数从多到少排列
- 仅统计已完成的答题（对方已作答的题目）

#### 2.5.5 空状态

若还没有任何答题记录，显示：

```
📊 好友默契排行榜

还没有答题记录，去给朋友出题吧！
                [去出题]
```

#### 2.5.6 访问权限

- 好友可见：A 进入 B 的默契问答页面时，可以看到 B 与所有好友的排行榜
- 自己查看自己时同理
- 非好友跳转登录

## 三、不做事项

| 事项 | 原因 |
|------|------|
| 更多新插件开发 | 当前 2 个插件 + 排行榜功能已覆盖核心需求，暂不扩展 |
| SDK / 开放插件生态 | 小于 100 人的圈子不需要 |
| Phase 6 功能 | 纪念日、投票、相册等暂不启动 |
| 动态/聊天/搜索改造 | 保持现状 |
| 管理员匿名追溯 | 已有完整实现，无需改动 |
