## 三、数据契约

### 3.1 BasePlugin 扩展方法

```python
class BasePlugin(ABC):
    # ... 现有 ...

    def get_summary(self, request_user_id: int) -> dict:
        """
        返回格式:
        {
            "type": str,
            "name": str,
            "icon": str,
            "description": str,
            "data": { ... },       # 插件相关摘要数据
            "is_active": bool,     # 全局是否启用
            "route": str,          # 跳转路径
        }
        """
        return self.get_profile_data(request_user_id)

    def get_profile_card_data(self, viewer_id: int, owner_id: int) -> dict | None:
        """
        返回 None 表示不展示（无数据），格式同 get_profile_data
        viewer_id = owner_id 时等同于 get_profile_data
        """
        return self.get_profile_data(owner_id)
```

### 3.2 新增 API 端点

| 端点 | 方法 | 用途 | 请求参数 | 响应 |
|------|------|------|---------|------|
| `/api/v1/plugins/summary/` | GET | 所有已启用插件的全局摘要 | — | `{code:0, data:[PluginSummary]}` |
| `/api/v1/profiles/{userId}/plugin-cards/` | GET | 某用户主页的插件卡片数据（访客视角） | — | `{code:0, data:[PluginCard]}` |
| `/api/v1/plugins/quiz/leaderboard/` | GET | 好友默契排行榜 | — | `{code:0, data:{rankings, avg_match_rate, total_friends}}` |

### 3.3 PluginSummary 格式

```json
{
    "type": "quiz",
    "name": "默契问答",
    "icon": "help-circle",
    "description": "和朋友互相出题测试默契度",
    "data": {
        "avg_match_rate": 75.5,
        "best_friend_id": 2,
        "best_friend_name": "李四",
        "best_match_rate": 92.0,
        "total_friends_answered": 6
    },
    "is_active": true,
    "route": "/plugins"
}
```

### 3.4 PluginCard 格式（个人主页卡片）

```json
{
    "type": "quiz",
    "name": "默契问答",
    "icon": "help-circle",
    "description": "...",
    "data": {
        "match_score": 87.0,
        "total_questions": 13,
        "correct_count": 11
    },
    "route": "/profile/123/plugins/quiz"
}
```

留言板作为静态特殊卡片也由 ProfilePluginCardsView 返回：

```json
{
    "type": "guestbook",
    "name": "留言板",
    "icon": "message-square",
    "description": "给我留言",
    "data": { "total_messages": 12 },
    "route": "/profile/123/guestbook"
}
```

### 3.5 Leaderboard 格式

```json
{
    "rankings": [
        {
            "rank": 1,
            "friend_id": 2,
            "nickname": "李四",
            "avatar_url": null,
            "match_score": 92.0,
            "total_questions": 13,
            "correct_count": 11
        }
    ],
    "avg_match_rate": 75.0,
    "total_friends": 6
}
```

### 3.6 layout_config 格式 (UserProfile.JSONField)

```json
{
    "show_plugin_area": true,
    "show_guestbook": true,
    "show_visitors": true
}
```

## 五、不做事项

- 不开发新插件（默契排行榜是 Tab，非独立插件）
- 不做开放 SDK / 插件生态
- 不动动态/聊天/搜索模块
- 不改动管理员匿名追溯功能
- 不迁移 `AdminAnonymousQuestionsView` 到插件目录（Phase 2 可选）
